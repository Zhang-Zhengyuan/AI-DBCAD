# ResumaCAD：选题覆盖与科研价值复核

核对日期：2026-10-26。用途：开题决策及 12 页组会汇报的证据底稿。本文补充昨日的[选题报告 PR #15](https://github.com/Zhang-Zhengyuan/ResumaCAD/pull/15)，不代表新方法已实现或实验已完成。

## 1. 决策结论

**建议推进有明确否证条件的开题预实验；现有证据不支持“没有任何人研究过”这一绝对判断。**

“CAD agent 的 memory”“长期 CAD”“记忆准入”“版本绑定与失效”“几何验证”各自都有先例。尤其 TRACE、Concord、Invalidation Contracts 与本选题存在直接概念重叠；TraceCAD、MUSE 和 CADForge 也说明 CAD/3D 研究已经开始系统使用记忆。将这些概念组合、换成 CAD 名称或存进图数据库，不能自动产生研究贡献。[R1–R12]

**这里要区分课题覆盖与方法先例。** Invalidation Contracts 的计费/食谱 API 实验没有直接覆盖 AI-CAD，也不使 CAD 中的新任务定义和 benchmark 失去价值。跨域迁移可以构成研究路线；贡献可以来自问题的系统化、公开评测、必要的领域适配及新实证发现，并不要求重新发明整个 memory 框架。本文要求与通用适配比较，是为了识别新增贡献，而不是把所有 agent memory 论文都视为已做完 CAD 课题。

本次定向核对中，**尚未找到对以下完整问题给出同等具体方法与系统评价的工作**：在人与 AI 交替修改、含外部变更的 CAD 版本链中，针对下一步操作所依赖的可执行几何查询，构造具有空间作用域、实例绑定及数值误差边界的有效性判据，在拒绝过时结论的同时保留仍然成立的谓词，并验证这种维护能改善可靠续作的质量与总成本权衡。这是当前可辩护的候选缺口，不是穷尽检索或法律意义的新颖性证明。

建议题名：**ResumaCAD：持续人机 CAD 编辑中的几何证据维护与可靠续作**。

英文工作题名：**ResumaCAD: Maintaining Geometric Evidence for Reliable Continuation in Human–AI CAD Editing**。

拟研究的核心问题可直接对老师表述为：

> 当 CAD 项目已经变化，AI 上次获得的哪些几何结论仍足以支持当前操作？系统能否用可计算的条件保留这些结论，并只复核必要部分，而不是依赖模型自行猜测或把整个项目重新检查一遍？

## 2. 本次如何查，能确认到哪里

使用网络检索发现工作，再阅读论文原文、正式论文页面或作者官方代码/文档。核心检索串包括：

- `"CAD" "memory" "long-horizon" agent editing`

- `"CAD" "memory" "invalidation contracts"`

### 2.2 局限

预印本和开源项目仍在快速变化；网页索引不能覆盖所有论文、工业内部系统或尚未公开工作。本文核对研究任务和机制，不独立复现实验表中的所有数字；未下载运行本次新发现系统。官方工程文档证明有人设计/实现相近能力，不等于其论文贡献、完整正确性或实测效果已获独立确认。后续在正式投稿前还需更新检索。

## 3. 哪些内容已经被覆盖

### 3.1 CAD 与 3D 编辑并非只有单次生成

**mrCAD** 已研究多轮人类交流下的 CAD 创建和细化，正式论文报告 6,082 个交流游戏、15,163 轮指令执行。它使“首次研究多轮 CAD”这一主张不成立。其重点是多模态沟通和目标细化，不能直接推出本文拟研究的版本变化后几何证据有效性已经解决。[R1]

**neuralCAD-Edit、AgenticCADedit、IterCAD** 已建立专家编辑请求、保留编辑过程状态、工具反馈与局部修改等路线。我们的现有 harness 复现属于实验基础，不能作为新的研究贡献。[R2–R4]

**CADWorld** 明确研究 long-horizon CAD computer use，并对保存的项目产物执行任务级检查。因此“第一项长周期 CAD 评测”不成立。其公开工作流主要评估单个任务内的长操作链；本题还需专门隔离用户/其他主体变更之后，过去查询与未提交计划能否继续使用这一因素。[R5]

**HistCAD** 已将显式约束、可编辑历史及编辑后应保留的约束纳入表示和评价。不能把约束保留或 history 本身当创新。建模操作历史与多人跨会话版本历史应分别定义。[R6]

### 3.2 最接近的 CAD memory 先例

**TraceCAD** 把需求状态、建模步骤、失败证据、修复候选与结果连接为持久恢复状态，进行依赖区域内的局部修复，并积累可复用修复技能。这直接覆盖“CAD agent 记住已满足需求并避免修坏其他部分”。其公开方法主要围绕生成与修复轨迹；本文候选增量必须落在外部版本变化后的几何查询有效性，而不能重述 persistent recovery。[R7]

**MUSE** 已用 Working/Scene/Skill Memory 支持三维场景中的需求满足与保留式编辑。附录 C.2 还评估 50 条三阶段连续编辑链，故“所有相关系统都不考虑连续编辑”是错误说法。其主要对象是场景与受控短链；它仍是本题非常接近的状态继承与外部验证路线。[R8]

**CADForge** 在单视图重建中保存组件参数字典，按依赖组件检索以减少完整历史的传递。这证明 CAD 专用结构化记忆和 token 节约已有工作；“把模型 JSON 化后检索”本身不足以构成新方法。[R9]

### 3.3 Agent memory 已经研究“能不能继续相信”

**Concord** 将工具观察绑定到可变来源，资源适配器接收版本及范围变化，框架更新、标记或抑制过时上下文。CAD 可以自然成为它的新资源适配器。因此，只给 CAD 观察附版本和依赖，再按变化失效，是它的领域适配范围，必须作为强对照。[R10]

**TRACE** 专门讨论 agent 离开、共享状态变化、返回后的 temporal memory admission，包含显式/隐式失效、来源核验、当前义务覆盖与预算选择。这与“续作前记忆门禁”高度重合。本文不能声称首次提出返回时准入；需要把 CAD 几何判据及其相对通用验证器的收益说清楚。[R11]

**Invalidation Contracts** 通过服务端版本信息、缓存提示、结构化差异及更细依赖控制跨 episode 记忆失效；实验域为合成计费/食谱 API，而非 CAD。它直接覆盖“环境变了、保留没过时的记忆以节约重新推导”。本题必须比较它的 CAD 查询适配，不能仅以“已有记忆系统不处理失效”为动机。[R12]

**PerMIT** 提供持久记忆的确认门禁和显式信任边界，主要针对注入与投毒。安全授权与几何事实新鲜度是不同属性：一个经用户确认、来源可信的旧测量，也可能因零件移动而失效。它排除了“有门禁就新颖”的主张，但不等于解决 CAD 变化下的数值/空间有效性。[R13]

### 3.4 工程实现已经很接近部分系统构件

**n3r/AgentCAD** 官方架构文档描述：部件检查结果按内容键缓存；装配检查键包含 specs 文本、实例 ID、部件缓存键与已解析变换；合并门禁将结果绑定到分支状态，若 head 变化则返回 pending。这意味着“版本化 CAD + 缓存验证 + 提交前门禁”已有公开工程设计。本文候选方法必须超出全内容键命中：例如变化已经发生时，对特定查询给出更精细、保守且可审计的保留依据。[R14]

**NVIDIA usd-content-agents** 官方 benchmark 文档也强调不可变来源绑定、需求符合性、几何有效性、编辑性、来源与交接完整性，并区分 authoring 与 handoff controls。不能把“产物带证据”或“检查输出而非只看图片”作为独占贡献。[R15]

**ARK** 官方项目记忆说明已明确区分持久语义记忆与当前 CAD 权威状态。这条工程原则与我们一致；将项目图当作记忆存储具有复用价值，但图数据库选型不构成核心研究新颖性。[R16]

## 4. 候选缺口为什么仍有研究价值

以下是基于上述公开机制的分析与拟研究假设，而非文献已经证明或本项目已经测得的结论。

### 4.1 空间“未发现”依赖的范围大于已返回的实体

一次查询若报告“这个插入区域里没有障碍物”，返回集合可能为空。只记录已返回实体的哈希将漏掉后来移入或新增的对象。证据需要约束**查询区域、候选对象集合/过滤规则及适用版本**，而不只是正例列表。

这不是全新的逻辑现象：数据库 phantom read 早已刻画查询结果集合因新增/变化行而改变的情形。[R17] 可研究的部分是如何把这类谓词依赖具体化为 CAD 中的保守空间域与下一步操作依据，并实测相对粗粒度空间失效的必要性。

### 4.2 几何已经变化，当前操作需要的谓词仍可能成立

例如旧最小距离为 5 mm，一侧形状的 Hausdorff 变化有可信上界 0.5 mm，另一侧不变，则新距离至少为 4.5 mm；若要求是至少 3 mm，阈值谓词仍可成立，但“精确距离仍为 5 mm”已不可复用。必须把**数值结果、误差界和当前用途**分开存取。

这种界及证书维护思想来自经典几何，不应包装成新的数学定理。Kinetic Data Structures 早已通过谓词/证书维护变化几何的数据结构。[R18] 候选贡献是适合 CAD 编辑类别的守卫、适用边界、不可判定时的回退，以及它在 AI 续作中的效益。

公差必须显式进入比较；近阈值、退化形状、单位/坐标系变化、缺少可证变化界时应重新查询或给出 Unknown，不能由 LLM 置信度替代几何保证。随意拓扑编辑通常没有便宜的可信变化界，首轮应限制在平移、已知参数编辑等可处理操作。

### 4.3 名称/身份相同不等于空间事实相同

同一个组件可以有多个 occurrence，刚体变换不同；布尔操作还可能切分、合并、重排面。证据绑定至少需要组件版本、装配实例、坐标系和可验证的对应关系。不能把本项目实体 key 或启发式匹配直接称为已解决 persistent naming。

实体对应是风险项和必要基础，而非默认新增一个“通用拓扑身份算法”贡献。初期可先按组件/实例稳定标识和保守 Unknown 回退推进，避免选题范围失控。

### 4.4 事实失效还会使未提交计划失去依据

“无干涉”证据过时后，基于它生成的插入/切削计划也应停止执行并重规划；提交需要绑定当前版本。只阻止 stale write 而不检查读到的几何假设，仍可能允许在当前版本执行错误操作。反之，合法新需求可以替代旧需求，不能把用户的新设计意图当成应禁止的矛盾。

### 4.5 研究价值来自可测的权衡

科学问题是**粗粒度来源变动与细粒度行动有效性之间的差异**。实用价值需体现为相同任务质量下较少的总查询、token、等待，或相同预算下更高的可靠完成率；只降低“失效证据使用率”但让系统全部拒绝行动没有意义。可行性来自现有 DBCAD 版本/资产链及 agent harness，核心查询可先用开放 OCP 求值器验证，再对接 ACIS，而无需重训基础模型。

## 5. 必须比较什么，怎样排除“只迁移 memory”

强基线至少包括：

1. 最新几何与当前有效需求，每次需要时重新查询；它拥有同等版本与历史访问权限。
2. 摘要/RAG 加最新状态；普通 memory baseline 不能故意不给关键更新。
3. 部件/实例内容键失效，包括 specs、变换及候选集合版本，避免人为设置漏依赖。
4. 保守 AABB/操作影响域失效，再执行当前精确查询；这是必须认真实现的便宜强基线。
5. Concord / Invalidation Contracts 的 CAD 适配，明确适配器已经知道哪些依赖；必要时加 TRACE 的返回边界与义务覆盖。
6. 全量精确验证的诊断上界。它只能得到当前可观测状态，不能提前访问未来编辑或隐藏验收答案。

新方法相对上述协议的区别应写在 CAD query adapter 和 validity guard 中；复用通用记忆框架本身不是缺点，但应准确归属贡献。消融分别移除空间否定范围、谓词/精确值区分、实例/公差绑定以及计划依赖回退；不能只与“完全无记忆”比较。

## 6. 如何开始及何时停止扩张

### 6.1 首轮诊断与双轨 benchmark

先拟定 20 个小型机械场景，每场景 6 类变化，组成 **120 个冻结检查点**。这是计划规模，不是已完成数据，不是 120 条长链。变化应含无关修改、隐式空间失效、阈值仍成立、近阈值、实例变换、合法需求替代；不只构造让新方法获胜的难例。

冻结轨在同一真实状态上比较证据判定，使用内核查询建立独立标签；闭环轨让各系统继承自己的输出，再施加同义外部编辑，检验错误是否传播。不能每轮强行载入 gold 快照覆盖系统输出。几何模板、部件族与操作模式分离训练/开发/测试，控制构型与公差随机性，并加入经工程人员核验的自然编辑链。

较长的 5/20/50 阶段链在短链诊断有效后逐级扩展；版本数、上下文长度、几何规模和变更范围分别控制。先固定模型及 harness，再验证第二模型/第二 harness，不把模型差异与证据方法差异混在一起。

### 6.2 评价与立项门槛

同时报告任务/整链成功、非目标约束保留、过时证据实际使用、有效证据保留、Unknown/拒绝率、恢复步骤、总 token/费用/耗时及精确查询开销。置信区间按独立场景/链聚合；不能把同一场景派生的所有检查点当成独立样本。不能用 VLM 自评代替关键数值验收。

建议首先要求：与全量复核相比保持任务质量；与内容键、AABB 和通用协议适配相比，确实出现有实际意义的总成本或可靠性改善。此前报告中“精确查询减少 30%”是拟议工程目标，不是既定成功事实；最终以总体质量—成本权衡和统计不确定性判断。

出现以下结果应收缩或停止相应方法主张：

- AABB 加当前查询已经覆盖几乎所有案例，新守卫的维护成本抵消收益。
- 通用协议加合理 CAD 适配得到等价效果，剩余变化只是接口包装。
- 过时证据错误在真实链中极少，或错误主要由目标定位/基础建模能力引起。
- 收益只在定制合成例子上出现，迁移到独立部件族、用户链或第二模型后消失。
- 因无法构造可信变化界而大量回退，复杂度却显著增加。

这些是研究判定标准，不预设需要得到正结果。即使方法路线失败，经过公正对照的失效分类和诊断集仍有价值，但能否形成论文贡献要另行评估。

## 7. 向老师汇报时的推荐表述

可以说：“已有工作分别推进了 CAD 编辑记忆与通用上下文一致性。我们拟研究持续人机编辑中，几何变化之后旧查询如何以可计算条件继续支持行动，建立外部变化可控、独立内核验收的 benchmark，再验证专门的几何证据维护是否优于通用失效协议和保守空间复核。”

不应说：“AI-CAD 还没有 memory”“第一项长期 CAD 研究”“别人没有做过版本或约束”“图数据库天然解决语义记忆”“已经证明本方法可以降本/保证正确/发表论文”。

**科研价值判断：值得先投入一个受控预实验周期；长时间投入应由强基线差距和真实案例频度来决定。** 研究重点应从笼统的 memory 系统，收敛到几何证据在变化下的可行动有效性。

# EXP-002 执行协议 v4（正式批次）

范围：AgenticCADedit 固定上游 `c084034cdcf462025a60ee70c5ba94577428e5ca` 的 MCP 工具与持久 CadSession；客户端增加冻结检查点和恢复策略。不是作者发布的原始持续编辑 benchmark，也不是完整长期协作复现。上游不修改。

## 问题与固定比较

检验在正确旧测量之后，外部编辑是否使几何依据过期，以及同一模型在可访问当前状态时是否因此错误续作。两类合成场景：圆柱定位销、矩形滑块。仅判断指定最终位置的可行性；不声明运动路径无碰撞。

任务：只平移 movable 到指定 X；要求到 obstacle 的表面距离至少 3 mm，且不与其他组件相交。若不可行，保持当前场景并明确说明被阻止。可行对照必须真实完成移动。固定组件不能更改。

四种事件，每个场景各一组：

- E0：没有外部修改，距离仍为 5 mm，版本 0。
- E1：仅远处辅助件移动，相关距离仍为 5 mm，版本 1。
- E3：障碍进入目标区域，目标组件不变，当前候选发生相交，版本 1。
- E4：障碍使间隙从 5 mm 变为 2.5 mm，小于 3 mm，版本 1。

三种策略：

- N：完整真实旧工具历史和代理预检计划继续；允许自由查询当前状态。
- F：仅保留当前任务、有效要求和工具约定，按需查询；不保留旧观测。
- A：与 F 相同，再预取当前 inspect、全部 faces/edges（这些小场景 limit=200 不截断）、候选对所有固定件的距离与交叠体积，以及两张官方渲染。这里“完整”仅指这个明确查询族，非任意 B-Rep 性质。

所有方法同一模型、工具、要求和变更通知。E1/E3/E4 均只通知外部编辑已提交和版本 1，不泄露事件类别、真值或变动位置；E0 通知版本 0 且没有变化。N/F 仍可主动渲染并看到新几何。任何模型返回的图片都按官方方式加入后续上下文。版本通知本身可能有效，需如实解释。

## 检查点与实际执行

模型先在实际官方 MCP 服务器上进行预检，构造候选位置并测量距离/相交；此时不得修改几何。控制器在成功的真实 run_step 已包含 distance 和 intersect 查询之后立即暂停，不依赖模型自行 finish。候选构造代码及明确目标构成待执行计划，正确旧观测必须在返回的工具输出中可核对。保存原始消息、工具调用及 STEP。用于主批的检查点必须几何不变，且人工核对确实获得正确旧观测；失败保留，不能无痕重试。暂停判定不使用未来事件真值。

每个恢复分支重建相同检查点，重放其真实 run_step/undo/reset 以复原变量，外部编辑同时更新 movable/obstacle/fixture/auxiliary/parts/result 等规范绑定。导出当前 STEP，独立检查与预定新场景一致，审计输出不喂给代理。模型自身缓存的中间变量可能持久存在，若造成错误，须区分陈旧对象绑定与旧文本依据。finish 额外补合法 tool response，使旧会话可被 API 再次接受。

模型配置沿用上游 Qwen MCP 的系统提示、完整操作约定和采样参数；通过现有已配置 API 别名 Qwen3.6-27B 调用，具体权重修订 unknown。temperature=0.6、top_p=0.95，未指定模型采样 seed；20261026 仅用于固定分支运行顺序。输出上限 4096，预检最多 8 次、正式恢复最多 12 次模型调用，无自动付费重试；迭代耗尽、无工具终止、异常均保留。与计划中建议的 2048 有差异，避免把正常工具回答过度截断。

开发修订保留：最初 4 次预检调用上限下，pin 因不存在的 intersects 方法及误用回滚变量耗尽调用；随后统一补充准确 API/回滚说明并增加到 8 次。slider 在完成测量后越过预检要求继续编辑，故增加控制器的测量后暂停。开发 4 个恢复分支使用 6 次上限，其中一项已得到正确目标几何但验证未结束，另一项先违规移动再发现新间隙不足且未完成修正。因此正式批次统一增加到 12 次，区分中间违规与最终结果。所有修订早于任何正式批次，旧尝试和费用完整保留，详见本地 development-amendment*.json。最终协议为 v4；不混合开发与正式分母。

开发批：独立平移后的场景，两种场景各一个真实预检，4 次恢复（pin/E0/N、pin/E3/F、slider/E1/F、slider/E4/N）。开发后审查并另存 freeze.json，再生成主批检查点与运行 2×4×3=24 个恢复；固定随机种子 20261026 排序。主批协议变化必须另存修订，不能覆盖此前结果。开发和主批分别报告。

## 独立真值、评分与归因

解析有符号间隙与 OCP 最短距离交叉核对；相交体积单独计算。最终 STEP 重新导入，以实体对称差体积比较“当前初始场景”和“当前目标场景”，阈值 1e-5 mm³，同时检查 shape.isValid。此评分也检查全部固定组件保持，不采用模型自评分。

几何通过要求：finish 且可行时真实到目标，不可行时保持当前初始场景。完整任务通过还要求不可行时公开说明被阻止；人工逐条审计，单独存标注与原始消息索引。无响应或只 finish 的停工不是有依据的成功。主要分母固定为全部 24 个分配的恢复尝试，失败/未知/预算中断均不能删除。未执行的分配格与已执行失败区分。

人工归因仅使用公开语句、工具参数与结果，不依赖私有推理：旧观测是否失效、是否重新测量、是否明确引用旧值、是否作出违反要求的行动、是否回退修正。证据不够则 unknown；仅工具用错/普通建模失败不归因为证据失效。最终成功与中途不安全动作分别统计。

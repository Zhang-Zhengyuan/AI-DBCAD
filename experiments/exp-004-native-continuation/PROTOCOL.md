# EXP-004 冻结前协议 v1

研究问题：在官方 AgenticCADedit 原样决策循环、完整 ACIS 工具与版本通知下，真实连续编辑后，人工改动是否导致旧几何观测进入不满足既有约束的续作？不预设必然失败，也不把一般建模错误归因为记忆。

## 设计

两类合成装配场景 pin/slider，沿用 EXP-002 的轴向间隙机制，以 ACIS 原生图元、SAT 与版本清单重建。每类有 movable、obstacle、fixture、auxiliary 四组件。movable 只能纯 X 平移，目的地与最低 3 mm 间隙在初始需求中明确；固定组件不得被 AI 改动。仅在明确要求时可以平移 auxiliary。若目的地不可行，保持模型并解释阻塞。

先完成十个真实用户需求阶段：初始检查、短距离移动、返回、到目的地、真实距离/干涉测量、返回起点、辅助件移动、约束核对、辅助件返回、计划预检。每阶段调用正式 job 入口与官方循环，继承实际上一阶段对话和几何；不以参考答案替换失败产物。只读阶段由宿主禁止写操作。

十阶段前缀完成后，保留实际产物和完整记录，分叉为成对的研究分支。若前缀不满足预先声明的起点和保护组件条件，记录前序失败，全部后续分母保留，不能悄悄重做。该设计是“十阶段连续前缀之后的受控分叉”，不是三十条独立自然长期对话。

每场景五个外部条件：E0 无变化；E1 只平移无关 auxiliary；E2 缩小间隙到 2.5 mm，同时用户明确将最低间隙从 3 mm 改为 2 mm（合法需求更新）；E3 将 obstacle 移入目的地使其相交；E4 缩小间隙到 2.5 mm、没有相交但不满足 3 mm 约束。人类操作只作用于实际前缀产物。所有策略获得相同的版本变化通知和工具权限，不直接告知变化是否相关。

每条件三种策略：N 完整历史；F 清除旧模型观测和模型推断、保留全部用户要求，按需查询；A 完整历史并刷新任务相关完整查询族。A 的刷新来自当前 ACIS inspect、面边、各组件对距离/干涉以及公开轴对齐几何的候选间隙计算，绝不读取隐藏目标答案。N/F 可通过相同工具获取这些信息。

分支阶段十一要求执行先前计划，遵守全部约束，不能通过更改目的地或固定组件使任务“成功”；不可行时应保持场景并报告。阶段十二要求复查、必要时返回起点恢复约束，保留实际阶段十一产物和历史。所有 ready 候选在隔离实验项目中按预先声明的自动审阅策略应用，独立真值不参与是否应用的决定。这不是生产系统的无人批准发布。

主要分母为 2 场景 × 5 变化 × 3 策略 = 30 分支，每分支两个续作阶段；十阶段前缀每场景只运行一次并共享。固定 seed 20261028 打乱分支顺序。主模型与可选强模型复核在运行配置中预先声明；不得因哪种模型失败而更换主模型或选择性执行条件。

## 判定

以真实 SAT 清单、轴对齐解析间隙、尺寸/体积/组件保护和 ACIS 独立查询为几何判据，不使用模型自评分。参考答案不进入生成上下文。目的地候选的旧间隙为 5 mm，当前真值由实际外部变化后的几何计算，不能用任务答案修复轨迹。

分别统计：阶段十一正确放置/正确保持、显式阻塞说明、阶段十二最终约束满足、保护组件修改、首次成功 run_step 后可见预览违反约束、正式实验版本是否违反约束。一次 run_step 内部命令后又原子回滚的临时状态不算模型可见的主违规指标，另作尝试诊断。

过期证据误用只在公开输出重复过期数值/实体事实并将其用于当前行动，且几何证据与时间顺序支持时标 confirmed。仅“先动后查”或最终失败不自动归因于记忆；标 unknown/general_modeling/repair_failure 等。归因由执行 agent 审阅，不伪称独立人类盲审。

若 N 与强基线均可靠续作、或观察到的失败主要源于适配/基础工具，则本轮不支持所期望的记忆失效论点。样本量、单一模型别名及合成场景不能用于估计工业发生率或宣称成熟 CAD agent 普遍失败。

## 运行与预算

开始主运行前冻结协议、源码及底座/上游哈希、完整任务、分母、模型/采样、最大调用和预算快照。每阶段最多 8 次调用，可在正常 round_limit 时原任务续作一次；网络/未知费用/工具崩溃不自动重试，不删除失败。输出 8192 token，temperature 0.6、top_p 0.95，模型采样 seed 未固定；队列 seed 不代表模型确定性。

本次所有新增调用共享既有授权 ¥300 账本，原有费用/未知预留保留。包括预检、探针、失败、续作和判定；费用不足时保留未执行分母并明确预算截断。每轨迹独立新目录，不覆盖运行。完整 messages、实际 API 响应、工具事件、每阶段清单、几何与账本留本地 runs/，共享摘要必须附来源和哈希。

原生几何与官方循环用真实进程；项目/版本存储使用隔离内存适配器，并持久化实验清单以便审计，不把本轮说成 Neo4j 生产持久化验收。无写入公共模型库，不改在用服务。

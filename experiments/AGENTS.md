# 实验补充规则

继承根 AGENTS.md。先读 [实验索引](README.md) 与 [目录/收录规则](../docs/REPOSITORY_LAYOUT.md)。

- 每个实验有唯一 `EXP-NNN`、`exp-NNN-slug/experiment.json` 和 README；定义中写研究问题、对照、主要指标、独立真值、失败与否证条件。新实验从 `_template/` 复制，不复用旧 ID。
- 定义状态与执行状态分别记录；计划、合成反例、旧单轮结果不能说成长期证据失效的实证。冻结检查点和闭环链分别报告；普通误差累积不自动归因为记忆失效。
- 定义和可复用代码可纳入 Git；每次运行的配置、run.json、原始响应、几何文件、图片、日志和账本留忽略目录，不能自动 push 或 PR。必要的脱敏小型摘要经判断后放 `results/`，附来源与哈希。
- 每次运行新建唯一目录，记录实际版本、数据、种子、预算、成本和退出状态；不覆盖失败运行，不清空账本，不把漏评样本从分母删除。付费调用遵循明确的本轮授权，登记实验不构成花费授权。
- 同一模型/工具/变更通知权限下比较全量重读/重验等强基线，核算上下文、查询、维护和判定的总成本；区分合法需求更新与旧证据误用。
- 底座能力放 `systems/dbcad/` 对应模块；实验专用代码放本实验，跨实验复用后再提取到 `research/`。底座不能反向导入实验模块。
- 完成定义后运行 `python3 scripts/experiments.py check`；改评分/协议保留原口径和版本，不重写已有结果。
